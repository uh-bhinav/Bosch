# Documentation Index

Use these documents for demo preparation, validation, and final reporting.

| Document | Purpose |
|---|---|
| `IMPLEMENTATION_STATUS.md` | Current truth source for implemented, approximate, and planned capabilities. |
| `DEMO_SCRIPT.md` | Step-by-step Level 1 live demo script with fallback wording. |
| `DFM_REPORT_OUTLINE.md` | Bosch-style DFM report structure for future PDF export and manual report assembly. |
| `SLIDE_STORYBOARD.md` | 7-10 minute presentation storyboard. |
| `EVIDENCE_CHECKLIST.md` | Metrics, screenshots, and claims checklist before submission. |

Recommended prep order:

1. Run validation and profiling in Docker/conda.
2. Capture screenshots listed in `EVIDENCE_CHECKLIST.md`.
3. Fill Part1 metrics into `DFM_REPORT_OUTLINE.md`.
4. Rehearse `DEMO_SCRIPT.md`.
5. Build slides from `SLIDE_STORYBOARD.md`.
